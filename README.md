# Smart Diabetes Health Platform

## اسم المشروع

منصة ذكية لإدارة ومتابعة الحالة الصحية لمرضى السكري

## فكرة المشروع

منصة رقمية تهدف إلى مساعدة مرضى السكري على تسجيل وإدارة بياناتهم الصحية،
ومتابعة تطور قراءات مستوى السكر، وتحليل اتجاهاتها، وحساب مؤشر لاستقرار
الحالة الصحية، وإرسال تنبيهات عند اكتشاف قراءات أو أنماط غير طبيعية.

كما توفر المنصة لوحة تحكم للطبيب تمكنه من متابعة المرضى عن بُعد،
والاطلاع على التقارير والمؤشرات الصحية وترتيب الحالات حسب أولوية المتابعة.
